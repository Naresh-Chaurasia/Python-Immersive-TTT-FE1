== Overview

This Jupyter notebook introduces the fundamentals of building AI agents using LangChain. It covers prompt templates, LLM chains, custom tool creation, and agent initialization with the ReAct (Reason + Act) pattern. The notebook demonstrates how to create agents that can reason about a problem, select appropriate tools, and iteratively refine their approach to answer user queries.

== Prerequisites

* Python 3.10+
* LangChain and related libraries
* OpenAI API key (set as environment variable)
* Tavily API key (optional, for web search)
* DuckDuckGo search (no API key required)

=== 7. ReAct Agent Behavior Explanation (Cell 9 - Markdown)

A detailed markdown explanation of the ReAct agent's reasoning process:

* **Thought**: Agent analyzes the question and decides which tool to use
* **Action**: Agent selects and invokes a tool
* **Observation**: Agent receives the tool's output
* **Loop**: Agent evaluates if the answer is sufficient; if not, it retries with a different approach
* **Final Answer**: Agent provides the best answer or admits inability

The execution cycle is illustrated as:

....
Question → Thought → Choose Tool → Execute Tool → Observe Result → (Enough? No → Think Again) / (Enough? Yes → Final Answer)
....

== Key Concepts

=== ReAct (Reason + Act) Pattern

The agent follows a cycle of reasoning and action:

1. **Reason**: Analyze the question and determine what information is needed
2. **Act**: Choose and execute a tool to gather information
3. **Observe**: Process the tool's output
4. **Repeat**: If the answer is insufficient, try a different approach
5. **Conclude**: Provide a final answer or admit inability

=== Tool Types

| Tool | Description | API Key Required |
|------|-------------|-----------------|
| Custom Function Tool | User-defined Python function | No |
| DuckDuckGoSearchRun | Web search via DuckDuckGo | No |
| TavilySearchResults | Web search via Tavily | Yes (TAVILY_API_KEY) |
| WikipediaQueryRun | Wikipedia search | No |
| Summarizer | LLM-based content summarization | No (uses ChatOpenAI) |

=== Agent Type

* `AgentType.ZERO_SHOT_REACT_DESCRIPTION`: The agent uses tool descriptions to decide which tool to invoke. "Zero-shot" means it doesn't require prior examples — it reasons from scratch for each query.

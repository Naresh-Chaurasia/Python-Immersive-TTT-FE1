== Installing MCP Server in Claude

This entry registers a local MCP (Model Context Protocol) server named `LocalNotes` so that a Claude client (Desktop or Code) knows how to launch it.

[source,json]
----
"LocalNotes": {
  "command": "/opt/homebrew/bin/uv",
  "args": [
    "run",
    "--directory",
    "/Users/nareshchaurasia/nc/PYTHON-ARCHITECT/Python-Immersive-TTT/Frontier-Engineer/week4-mcp/3-mcp-server-deepdive-functionality",
    "--frozen",
    "--with",
    "mcp[cli]",
    "mcp",
    "run",
    "/Users/nareshchaurasia/nc/PYTHON-ARCHITECT/Python-Immersive-TTT/Frontier-Engineer/week4-mcp/3-mcp-server-deepdive-functionality/local-server.py"
  ]
}
----

*Field Breakdown*

`LocalNotes`::
The server name, used as its identifier in the client's tool list.

`command`::
The executable used to launch the server -- here, `uv`, the Astral Python package/project manager, installed via Homebrew on Apple Silicon (`/opt/homebrew`).

`args`::
The argument list passed to `uv`:
+
--
`run --directory <project-path> --frozen`::: Runs a command inside the given project directory using `uv run`. `--frozen` uses the lockfile as-is, without re-resolving dependencies.
`--with mcp[cli]`::: Ensures the `mcp` package (with CLI extras) is available in the ephemeral environment, even if not declared as a project dependency.
`mcp run <script-path>`::: The command actually executed -- the `mcp` CLI's `run` subcommand, pointed at `local-server.py`, which starts that script as an MCP server (typically over stdio).
--

*Summary*

TIP: Each time this client starts, `uv` spins up an isolated Python environment inside the `3-mcp-server-deepdive-functionality` project folder, guarantees the `mcp` CLI is present, and runs `local-server.py` as an MCP server via `mcp run`. The server then exposes its defined tools (note-adding and note-reading) to the Claude client.
